# Own-voice source recordings — trup

The ten trope-name recordings in Mordy's own voice (2026-07-03) plus the
librosa pitch-contour extraction (`taamim_clarinet_contours.json`) produced
from them by GPT. Recovered from `taamim_clarinet_synth_bundle.zip` and
committed 2026-07-08 so the ground-truth audio is version-controlled.

Provenance chain:

- These recordings are the source of the **Your Voice** bank in
  `apps/trup-real.html` (grade A — measured from recording, per the PRD's
  No-Fake-Mesorah policy; own voice, so embedding is rights-clean).
- `apps/_archive/taamim_clarinet_synth.html` is GPT's origin file — the
  first clarinet translation of these contours. Superseded by trup-real
  (which embeds the same mp3s for A/B) and archived per TRUP-HANDOFF.md.

Tropes: munach, pashtah, puzair, kadma-v'azlah, zakef kotoin, mahpach,
mercha, munach-esnachtah, munach-segol, munach-zarkah.
